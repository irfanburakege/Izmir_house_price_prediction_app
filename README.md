# İzmir House Price Prediction App

A small Streamlit app that provides quick estimations for house prices in İzmir, Turkey. The app uses a trained scikit-learn model (Random Forest) and a district-tier mapping created via K-Means clustering to adjust predictions by neighborhood market tier.

This repository contains:
- `app.py` — Streamlit application that loads the saved model and district tiers, accepts user inputs (district, size, rooms, age) and returns an estimated price with a small explanation of feature importances.
- `model.ipynb` — Jupyter notebook used for exploratory data analysis, data cleaning, district clustering (K-Means), model selection/comparison, and final model training. The notebook saves `model.pkl` and `district_tiers.pkl`.
- `model.pkl` — (binary) trained Random Forest regressor saved by the notebook. (Not always present in repo; regenerated by running the notebook.)
- `district_tiers.pkl` — (binary) dictionary mapping District -> Tier (1..4) produced by K-Means clustering.
- (Optional) `izmir_houses.xlsx` — original dataset used by the notebook (not included here by default).

Quick overview
- Inputs: District (selected from detected districts), Size (m²), Number of rooms, Building age.
- Output: Estimated price in Turkish Lira (TL) and a simple feature importance bar chart.
- Note: The model was trained on about 979 cleaned listings (see notebook). It does not account for details such as sea view, floor, furnishing, or internal condition.

Requirements
- Python 3.8+
- Main Python libraries used:
  - streamlit
  - pandas
  - scikit-learn
  - matplotlib
  - seaborn
  - openpyxl (if your Excel dataset is .xlsx)
  - Note: pickle is part of the standard library.

Example installation (recommended inside a virtual environment)
- Create and activate virtualenv:
  - python -m venv .venv
  - On macOS/Linux: source .venv/bin/activate
  - On Windows: .venv\Scripts\activate
- Install dependencies:
  - pip install streamlit pandas scikit-learn matplotlib seaborn openpyxl

Run the Streamlit app locally
1. Make sure `model.pkl` and `district_tiers.pkl` are in the repository root (the same folder as `app.py`). If they are not present, follow the "Retrain the model" steps below to generate them.
2. Run:
   - streamlit run app.py
3. The app will open in your browser (usually at http://localhost:8501). Use the sidebar to set District, Size (m²), Rooms and Age, then click "Predict Price".

Retrain the model (from the notebook)
- If you want to retrain or regenerate `model.pkl` and `district_tiers.pkl`:
  1. Open `model.ipynb` in Jupyter Lab/Notebook.
  2. Ensure `izmir_houses.xlsx` (dataset) is available in the same directory.
  3. Run the notebook top-to-bottom. The notebook:
     - Cleans the dataset (parses rooms, age, districts).
     - Filters out outliers and unrealistic listings.
     - Computes district average price and clusters districts into tiers using K-Means (k=4).
     - Tests multiple regressors (LinearRegression, DecisionTree, RandomForest, GradientBoosting).
     - Selects the best model (Random Forest in the notebook) and trains it on the full cleaned dataset.
     - Saves `model.pkl` and `district_tiers.pkl` via pickle.
  4. Copy the resulting `model.pkl` and `district_tiers.pkl` into the repository root (same dir as `app.py`).

Files and functions explained
- app.py
  - load_data() — cached loader that unpickles `model.pkl` and `district_tiers.pkl`.
  - Sidebar inputs — district, size, rooms, age.
  - Prediction — builds a DataFrame with features ['Rooms','Size_m2','Tier','Age'] and calls model.predict.
  - Displays estimated price and a bar chart of model.feature_importances_.
- model.ipynb
  - Data cleaning helpers: clean_room_count, clean_age, clean_district.
  - Outlier filtering and price-per-m2 checks.
  - K-Means clustering to map District -> Tier.
  - Model comparison and final training + pickle dump.

Limitations & Important Notes
- The dataset is relatively small (~979 cleaned rows). Predictions should be treated as rough estimates.
- Many influential features are missing (view, floor level, internal condition, proximity to transport/amenities), so the output is a simplified market estimate.
- Outliers and exceptional properties may cause large prediction errors.
- The district tiers are coarse groupings; local sub-neighborhoods may vary significantly.
